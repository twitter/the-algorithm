# Xalgo CLI - AI-Powered X/Twitter Algorithm Explorer

**Xalgo** is an intelligent CLI tool that lets you explore and understand the X (formerly Twitter) algorithm through conversational AI interactions.

## Features

- **Multiple AI Provider Support**: Choose from ChatGPT, Claude, Deepseek, Mistral, Grok, and more
- **Conversational Interface**: Chat-like experience with conversation history
- **Local Storage**: Save and resume conversations locally
- **Beautiful CLI Interface**: Styled with colors and ASCII art
- **Easy API Key Management**: Simple configuration for all AI providers
- **Algorithm Exploration**: Deep dive into X's recommendation algorithms, ranking systems, and more

## Installation

1. Clone this repository
2. Navigate to the Xalgo folder
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the CLI:
   ```bash
   npm start
   ```

## Usage

1. **First Launch**: Configure your AI provider API keys
2. **Start Chatting**: Ask questions about the X algorithm
3. **Switch Providers**: Change AI models on the fly
4. **Save Conversations**: All chats are automatically saved locally
5. **Resume Chats**: Load previous conversations anytime

## Supported AI Providers

- **OpenAI** (ChatGPT)
- **Anthropic** (Claude)
- **Deepseek**
- **Mistral AI**
- **Grok** (xAI)
- **Google** (Gemini)

## API Key Configuration

The CLI will guide you through setting up API keys for your preferred AI providers. Keys are stored locally and securely.
