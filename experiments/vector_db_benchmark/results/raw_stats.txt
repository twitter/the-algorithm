Vector DB Benchmark - Raw Stats
================================

Setup:
  - 50,000 index vectors, 1,000 queries, 128-dim, L2-normalized
  - 50 Gaussian clusters with cluster_std=0.3
  - Cosine similarity / inner product on unit vectors
  - k=10
  - 50 warmup queries before timed loop
  - Ground truth: exact brute-force top-10

Build time notes:
  - FAISS-HNSW shows real build time (~31s) only for the first ef_search config.
    The other 3 configs share the same index (ef_search is a query-time param),
    so build_ms=0 for those.
  - Qdrant local mode is shown for transparency but performs exact search,
    not HNSW. Real Qdrant HNSW requires a Docker/cloud server.

Key takeaways:
  1. FAISS-IVFFlat dominates the Pareto frontier (recall vs latency).
     - nprobe=64 reaches recall=0.95 at p50=1.7ms.
  2. FAISS-HNSW gives a smoother recall curve but costs ~30s to build and
     is consistently more expensive than IVFFlat at matched recall.
  3. Annoy is strictly dominated by FAISS on this dataset.
  4. Qdrant local mode does exact search regardless of HNSW config.
     Latency ~55ms p50 is 22x slower than NumPy brute-force for identical
     results, entirely due to Python/serialization overhead.
